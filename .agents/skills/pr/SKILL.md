name: pr
description: Create or update GitHub pull requests and their descriptions. Use when asked to open a PR or revise its title or body.
---

- Read and adhere to the repository's PR template.
- Describe the final diff concisely, including relevant validation and limitations. Omit conversational history.
- When updating work with an existing PR, update that PR unless a new one is requested.
- Verify the submitted title and body, then return the PR link.
